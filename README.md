# pst-careers-poster

[![Ask DeepWiki](https://deepwiki.com/badge.svg)](https://deepwiki.com/opengovsg/pst-careers-poster)

A weekly cron job that picks a noteworthy slice of Singapore Public Service IT vacancies and posts a featured roundup to LinkedIn — one feature themed by a trending job title, another by hiring agency.

## If you landed here from one of the posts

Browse all live tech roles across the Singapore Public Service at **[go.gov.sg/pst-roles](https://go.gov.sg/pst-roles)** — the same link appears at the bottom of every post we publish. Or head straight to **[jobs.careers.gov.sg](https://jobs.careers.gov.sg)** to filter and apply.

We hire across engineering, product, design, data, and security, across many agencies, with roles open to both fresh grads and mid-career switchers.

## If you're here for the code

See [`AGENTS.md`](./AGENTS.md) for the full architecture walkthrough — it doubles as guidance for AI coding agents (Claude Code, Copilot, etc.) working on this repo. The short version: it's a  Vercel Workflow where post generation runs as durable workflow steps.
